# Offline Notes — PWA-приложение для заметок

Простое прогрессивное веб-приложение (PWA) для управления заметками, которое работает **полностью офлайн**.

## Возможности

- Добавление и удаление заметок
- Хранение данных в `localStorage` — заметки сохраняются между сессиями
- Полная работа без интернета благодаря Service Worker и стратегии Cache First
- Установка на устройство как нативное приложение (PWA)
- Поддержка Android, iOS и десктопа
- Индикатор статуса соединения (онлайн / офлайн) в реальном времени

## Технологии

| Технология | Назначение |
|---|---|
| Vanilla JS | Логика приложения |
| Service Worker | Офлайн-кэширование (Cache First) |
| Web App Manifest | Установка как PWA |
| localStorage | Персистентное хранение заметок |
| CSS Custom Properties | Стилизация |

## Структура проекта

```
frontend/
└── notes-app/
    ├── index.html      # Разметка приложения
    ├── app.js          # Логика: заметки, события, SW-регистрация
    ├── style.css       # Стили
    ├── sw.js           # Service Worker — кэширование и офлайн-фолбэк
    ├── manifest.json   # Web App Manifest
    └── icons/          # Иконки всех размеров (16–512px)
```

## Запуск

Для корректной работы Service Worker приложение нужно открывать через HTTP-сервер (не через `file://`):

```bash
# Через любой статический сервер, например:
npx serve frontend/notes-app

# Или Python:
cd frontend/notes-app && python3 -m http.server 8080
```

Открыть в браузере: `http://localhost:8080`

## Как работает офлайн-режим

1. При первом посещении Service Worker устанавливается и кэширует все статические ресурсы.
2. При последующих запросах ресурсы отдаются из кэша (Cache First), без обращения к сети.
3. При потере соединения приложение продолжает работать — все данные берутся из кэша и `localStorage`.
4. При обновлении файлов меняется версия кэша (`CACHE_NAME`), старый кэш удаляется при активации нового SW.
